  • Safe Driver A webcam-based drowsiness alert that watches the driver's eyes and triggers an alarm circuit. Computer visionPrototype

    The problem

    Falling asleep at the wheel gives almost no warning. The system notices closing eyes early and raises an alert before it's too late.

    Stack

    • Python
    • OpenCV
    • dlib
    • NumPy
    • pySerial
    • Proteus

    How it works

    • Detects the face with dlib's HOG detector and places 68 facial landmarks
    • Computes an eye aspect ratio to classify the driver as active, drowsy or asleep
    • Uses frame counters so a single blink doesn't fire a false alarm
    • Sends the state over serial to an Arduino alarm circuit simulated in Proteus

    Status

    Working prototype with the hardware side simulated. The repository includes the Python detector, the Proteus project and a flowchart.

    Repository
  • Heart Disease Risk Prediction A PySpark model that estimates 10-year coronary heart disease risk from the Framingham study. Machine learningStudy

    The question

    Can a few clinical measurements, such as age, blood pressure, cholesterol and smoking, flag people at higher risk early?

    Stack

    • Python
    • PySpark MLlib
    • Logistic regression
    • Matplotlib
    • Seaborn

    Approach

    • Cleaning and typing the Framingham dataset in Spark
    • Feature vector assembly and standard scaling
    • Logistic regression on a 70/30 train/test split
    • Evaluation with a confusion matrix, precision, recall and F1

    Result

    85% accuracy overall. The dataset is imbalanced and the model misses many positive cases, so class balancing and stronger models are the documented next steps.

    Built with Firas Chebbi.
